## 2. Corrected paired t test and subject-level bootstrap

- **Resampling unit**: the held-out subject (person; chb01 and chb21 together). A resample draws subjects with replacement and takes, for each drawn subject, the paired difference of the two operators, so both operators' results of a subject always enter together; operators are never resampled separately.
- **Second variant**: within each drawn subject, the five seed sets are also drawn with replacement (the same seed sets for both operators).
- **Iterations**: 10,000 per dataset (generator seed 20261022); the same draws are used for every pair.
- **Interval**: percentile 95% interval (2.5th and 97.5th percentiles).
- **Corrected test**: mean difference +- t(0.975, n-1) x SE, with SE^2 = (1/n + n_test/n_train) var(d) (Nadeau and Bengio), the same fold values (seed sets averaged).
- **Direction consistency**: share of bootstrap means with the sign of the observed mean difference.
- The bootstrap treats subjects as independent and does not model the overlap of the LOSO training sets, which the corrected test accounts for. The two rest on different dependence assumptions; the corrected test stays the primary analysis and the bootstrap is reported as inference sensitivity.

## 3. CHB-MIT prevalence-adjusted macro F1

**A. Definition.** For each case (CHB-MIT case folder; chb21 belongs to the same person as chb01 and keeps its own weight):

    w = N_nonictal,full / N_nonictal,sampled        (ictal windows: weight 1)

N_nonictal,full counts every non-overlapping 10 s window of the case's 683 target-montage recordings that does not overlap a seizure; N_nonictal,sampled the non-ictal windows drawn for the corpus (four per ictal window). Every ictal window is in the corpus, so the ictal class needs no weight. With prediction at the 0.5 threshold, each test window adds its weight to one cell of the confusion matrix:

    TP = sum over ictal windows predicted ictal (weight 1)
    FN = sum over ictal windows predicted non-ictal (weight 1)
    FP = sum of w over non-ictal windows predicted ictal
    TN = sum of w over non-ictal windows predicted non-ictal
    F1_ictal = 2 TP / (2 TP + FP + FN),  F1_nonictal = 2 TN / (2 TN + FN + FP)
    macro F1 = (F1_ictal + F1_nonictal) / 2

So TP and FN are unchanged, FP and TN are scaled up to the full non-ictal count. This assumes that the sampled non-ictal windows have the error rate of the non-ictal windows that were not sampled (they are a random sample within each case, seed 20260727); the result is a prevalence-adjusted estimate, not a measurement on all windows.
